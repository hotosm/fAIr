# API

All endpoints live under `/api/v1/`. Writes and owner-scoped reads require `Authorization: Bearer <token>`. The token is `FAIR_DEV_TOKEN` when `AUTH_PROVIDER=dev`, or a Hanko-issued JWT when `AUTH_PROVIDER=hanko`. `GET` on datasets, local-models, and predictions is open anonymously for rows with `visibility="public"`. Anonymous callers get 404 on private rows.

The running backend's OpenAPI schema covers every endpoint, including base models, categories, feedback, stars and user state. [Release QA](release-qa.md) uses these endpoints in run order.

| Path | Format |
| --- | --- |
| `/api/docs/` | Swagger UI, with a request body for each write endpoint |
| `/api/redoc/` | ReDoc |
| `/api/schema/` | Raw OpenAPI |

## Core flow endpoints

| Method | Path                                               | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------ | -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET    | `/health/`                                         | Dependency reachability report                                                                                                                                                                                                                                                                                                                                                                                                    |
| POST   | `/aois/`                                           | Create an AOI polygon (GeoJSON Feature)                                                                                                                                                                                                                                                                                                                                                                                           |
| GET    | `/aois/`                                           | List AOIs (bbox-filterable)                                                                                                                                                                                                                                                                                                                                                                                                       |
| POST   | `/datasets/build/`                                 | Enqueue a dataset build job. `title`, `description`, `category`, `aoi_ids`, `imagery` (TMS template per model input name, such as `{"image": ...}` or `{"post": ..., "pre": ...}`) or `source_imagery` (one TMS template, read as the `image` input), `zoom`, `label_tasks`, `label_classes` (an optional integer `value` per entry sets `properties.label`), `labels_url` (public https GeoJSON; when set, labels come from it), `keywords` (allowed: `building`, `road`, `tree`, `water`, `landuse`), `label_type`, `geometry_type` |
| GET    | `/datasets/{id}/?expand=stac`                      | Inspect dataset, with STAC metadata + presigned `labels` and per-input `chips` (`{input name: url}`) URLs once `status=built`                                                                                                                                                                                                                                                                                                     |
| POST   | `/datasets/{id}/{publish,unpublish}/`              | Toggle dataset `visibility` (anonymous read)                                                                                                                                                                                                                                                                                                                                                                                      |
| DELETE | `/datasets/{id}/`                                  | Delete a dataset and its STAC versions (owner or admin); 409 while it is building or training runs use it                                                                                                                                                                                                                                                                                                                         |
| GET    | `/local-models/`                                   | Local models with a STAC version; `?published=false` lists the caller's own drafts (no STAC version yet), `?published=all` both. Filter by `status`, `visibility`, `category`, `base_model`, `is_pinned`, `user`; order by `created_at`, `last_modified`, `star_count`                                                                                                                                                            |
| POST   | `/local-models/{id}/{publish,unpublish}/`          | Toggle local-model `visibility` (owner or admin); publishing a draft without a STAC version returns 409                                                                                                                                                                                                                                                                                                                           |
| POST   | `/trainings/submit/`                               | Enqueue a finetune. `base_model_stac_id`, `dataset_stac_id`, `model_name`, `overrides` (must match base-model's `fair:hyperparameters_spec`)                                                                                                                                                                                                                                                                                      |
| GET    | `/trainings/{id}/`                                 | Run state including `zenml_run_id`                                                                                                                                                                                                                                                                                                                                                                                                |
| GET    | `/trainings/runs/{run_id}/status/`                 | Force-poll ZenML; refreshes the DB row                                                                                                                                                                                                                                                                                                                                                                                            |
| GET    | `/trainings/runs/{run_id}/logs/?tail=N&step=name`  | Tail orchestrator or step logs                                                                                                                                                                                                                                                                                                                                                                                                    |
| POST   | `/trainings/runs/{run_id}/cancel/?graceful=true`   | Stop a running pipeline                                                                                                                                                                                                                                                                                                                                                                                                           |
| POST   | `/trainings/{id}/publish/`                         | Promote a completed run to a versioned local-model. Validates against base-model spec; writes a new STAC item under `local-models/`. Returns `local_model_stac_id`                                                                                                                                                                                                                                                                |
| POST   | `/predictions/submit/`                             | Enqueue inference. `model_stac_id`, `imagery` (TMS template or TileJSON URL per model input name, such as `{"image": ...}` or `{"post": ..., "pre": ...}`) or `image_uri` (one URL, read as the `image` input), `bbox` or a GeoJSON Polygon or MultiPolygon `geometry` (exactly one), `zoom`, `params` (keys must be the model's declared inference params; a `str` param without `values` must be empty or a public http(s) URL)                                                               |
| GET    | `/predictions/{id}/`                               | Status + assets (presigned) once `results_ready=true`                                                                                                                                                                                                                                                                                                                                                                             |
| GET    | `/predictions/{id}/result/`                        | The three presigned URLs (geojson / fgb / pmtiles); 409 until `results_ready`                                                                                                                                                                                                                                                                                                                                                |
| POST   | `/predictions/runs/{run_id}/cancel/?graceful=true` | Stop a running inference pipeline                                                                                                                                                                                                                                                                                                                                                                                                 |
| POST   | `/predictions/{id}/{publish,unpublish}/`           | Toggle prediction `visibility` (anonymous read of result)                                                                                                                                                                                                                                                                                                                                                                         |
