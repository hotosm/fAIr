# Contributing

Contributions are welcome, whether reporting a bug, improving the documentation, or adding a model.

## Code and issues

The contribution guide in the repository covers setting up a development environment, running the tests, and opening a pull request: [CONTRIBUTING.md](https://github.com/hotosm/fAIr/blob/develop/CONTRIBUTING.md). Please also read the [Code of Conduct](code-of-conduct.md).

To run the project while you work on it, see [Developer setup](../guides/developer-setup.md).

## Contributing a model

New geo-AI models are contributed through the model repository and registered into fAIr. See [Register a base model](../guides/register-a-base-model.md) and the developer role in [User bases](../overview/who-uses-it.md#developer).

## Releases

Shipped capabilities are listed in the [Roadmap](../roadmap/index.md), and every tagged release is on [GitHub](https://github.com/hotosm/fAIr/releases). Release versions are managed with [commitizen](https://pypi.org/project/commitizen/) (`cz bump`).
